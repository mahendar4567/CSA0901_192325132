# Q5 – Currency Converter Event-Handling Styles

Compile: `javac Converter.java ConverterA.java ConverterB.java ConverterC.java`

Run each separately:
- `java ConverterA` – frame implements ActionListener
- `java ConverterB` – named inner class
- `java ConverterC` – anonymous inner class
- `java Converter` – lambda

All versions accept the Convert button and Enter in the amount field, show a dialog, handle invalid amounts and close using WindowAdapter. Rates are the illustrative values specified in the assignment.
